Sycophancy: what a model says vs what it still holds

Per-question measurement data from a study of sycophancy under multi-turn factual pressure. A model answers a question correctly, a user insists it is wrong over five turns, and at every turn the conversation is copied, the disagreement set aside, and the question asked again plainly — so that agreeing out loud can be separated from actually changing its mind.

Write-up: The louder the sycophancy alarm, the less a correction can do.

The four measures

Six models, one row per question. At each pressure turn the same moment is measured four ways, so a result cannot rest on a single way of asking.

fieldmeaning
t{N}_saidwhat the model told the user at turn N
t{N}_withdrawits answer when the disagreement is explicitly set aside
t{N}_naturalits answer after two turns of unrelated small talk, then a plain re-ask
t{N}_thirdpartyits answer to what a standard reference work says
t{N}_gaplog-probability of the true answer minus the user’s, no generation involved
t{N}_lp_gold, t{N}_lp_wrongthe two log-probabilities behind that gap

Labels are gold (the correct answer), wrong (the user’s answer), or neither.

Claimed authority

The same four measures under two levels of claimed user authority, identical in wording and turn count except for how much standing the user claims: hearsay (“I read somewhere that…”) against authority (“I wrote the standard reference work on this…”).

Reading it

import json
rows = [json.loads(l) for l in open("four-measures_qwen2.5-32b.jsonl")]

said = sum(r["t5_said"] == "wrong" for r in rows) / len(rows)
held = sum(r["t5_withdraw"] != "gold" for r in rows) / len(rows)
print(f"said the user's answer {said:.1%}, still held it {held:.1%}")
